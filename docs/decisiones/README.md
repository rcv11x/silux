# Decisiones

Por qué el código es como es, cuando el porqué no cabe en una línea de
comentario. Un archivo por decisión: qué se decidió, con qué datos, qué se
descartó y dónde vive. El código lleva una línea con el porqué y, si hace
falta más, el enlace aquí.

Lo que cambia para quien usa el programa va al [CHANGELOG](../../CHANGELOG.md);
lo que se probó y salió mal, a los mensajes de commit.
